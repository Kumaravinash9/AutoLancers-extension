AutoLancers

This browser is already connected to AutoLancers.

There is nothing to configure here. The extension gets its backend address and its token from the AutoLancers app when you sign in, and everything else on this page is a deployment setting rather than a preference.

Open the toolbar icon on an Upwork or PeoplePerHour page to read it, or use Collect my pages… to gather several at once.

Where your AutoLancers backend is running.

Leave this empty to just scrape. Reading a page and copying the result needs no token at all. Add one only when you want a “Send to AutoLancers” button, which scores the job and files it in your queue. It's an AutoLancers token, not an Upwork one — the extension runs on Upwork's page, where your AutoLancers cookie isn't sent. Issue one with: 

curl -X POST localhost:8010/accounts/tokens \
  -H 'content-type: application/json' \
  -b "al_session=<your session cookie>" \
  -d '{"name":"Chrome extension"}'

The token is shown once and stored hashed — if you lose it, issue another and revoke the old one.

Collection only ever runs when you press Collect. There is no automatic trigger and no schedule.

Read page(s) at once — 0 means all of them. One is the default: about 76 seconds for eight pages, with a pause between each. Setting it to 0 takes about 4 seconds and has tripped Upwork's bot detection in practice — the browser was challenged for a while, though the account itself stayed fine.

— every job listing becomes a project, deduped on its marketplace id, so the same posting seen on Best matches and Most recent is one row scored once. Needs a token; with none set nothing is sent and nothing fails.

— costs tokens and seconds per page, and only runs when a field actually came back empty. It can never overwrite a value the selectors found, and it can never introduce a job that wasn't on the page: a job's id lives in its link, and a job with no id could not be deduped against the next collection.

— off by default, a run reads in a background tab that never takes focus. Turn this on to watch it work, or to step in when Upwork asks you to sign in mid-run.
